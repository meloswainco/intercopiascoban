🚀 Todo lo que necesitas saber

Este software fue diseñado con un objetivo claro: velocidad en el mostrador, control estricto de inventario y cero pagos mensuales. Aquí resolvemos las dudas más frecuentes sobre cómo funciona.

💰 Modelo de Negocio y Precios

  • 100% Libre de Mensualidades: Es un software de pago único. Compras tu licencia y el programa es tuyo para siempre. Olvídate de pagar alquileres mensuales por servidores en la nube.
  • Fase "Fundadores" (Q. 375.00): Si entras ahora, pagas el precio especial, participas en las decisiones de diseño y recibes acceso anticipado el 1 de octubre.
  • Venta General (Q. 770.00): A partir del 1 de noviembre, el software sale a su precio oficial para el público general.

💻 Instalación y Redes

  • Inventario Local para Máxima Velocidad: El sistema se instala en tu computadora y guarda datos localmente. Es rapidísimo y no se cae si te quedas sin internet.
  • Uso en varias computadoras (Sucursales): Eres dueño del instalador (2 o 3 PCs). Al no usar la nube, funcionan como cajas independientes con inventario propio.
  • ¿Cajas adicionales en red? El modo "Servidor" para conectar varias terminales dentro del mismo local está en nuestra hoja de ruta para el próximo año.

⚙️ Operación en el Mostrador

  • Inventario Flexible: Si olvidaste ingresar producto, el POS no te bloquea. Vendes, registra stock negativo (ej. -2) y te avisa sutilmente. Al ingresar compras, cuadra solo.
  • Corrección de Errores Segura: Usamos "Anular y Clonar". Con un clic anulas el ticket (devolviendo el stock) y el sistema carga los productos para corregir y cobrar al instante.
  • Control Interno (Sin FEL): Diseñado para tu control. No conecta a SAT ni certificadores. Para facturar, usa tu Agencia Virtual gratuita.

🖥️ Requisitos del Sistema y Hardware

  • Sistema Operativo: Exclusivo para Windows 10 o Windows 11. (No compatible nativamente con Mac/Apple).
  • Equipo Base: Con 4 GB de RAM y espacio básico en disco duro funciona perfecto.
  • Periféricos (Opcionales): Funciona con teclado y mouse, pero soporta lector de barras, gaveta de dinero y uso táctil.
  • Impresión de Tickets: Optimizado para impresoras térmicas de 80mm o 58mm. También funciona con hojas carta.
